# DBMS Lab Practicals

## About
This repository contains my Database Management System (DBMS) laboratory experiments completed as part of my B.Tech CSE (AI/ML).

The repository includes SQL queries, database creation, constraints, joins, views, stored procedures, triggers, and other DBMS concepts.

## Experiments

| Experiment | Description |
|---|---|
| Experiment 1 | ER Diagram and Database Design |
| Experiment 2 | Table Creation, Constraints, and Integrity Violations |
| Experiment 3 | SQL Queries: Selection, Projection, Aggregates, and Grouping |
| Experiment 4 | Joins, Subqueries, Set Operations, and EXPLAIN |
| Experiment 5 | Views, Updatability, and Recursive CTEs |
| Experiment 6 | Stored Procedures, Salary Validation, and Audit Triggers |

## Technologies Used
- MySQL
- SQL
- GitHub

## Repository Structure
Each experiment has its own folder containing:
- `README.md` — aim, description, source code, output details, and conclusion.
- `.sql` file — SQL code for running the experiment.

## Purpose
This repository is maintained for learning, practising, and documenting DBMS laboratory concepts.
